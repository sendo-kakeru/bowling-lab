スペアの取りこぼしが多いので、立ち位置を感覚ではなく数字で決めることにした。よく知られている「3-6-9」の考え方を、自分の投げ方に合わせて書き直したもの。

## 基本の考え方

ストライクのときの立ち位置と目標を基準にして、残ったピンに合わせて立ち位置だけを動かす。目標の矢印は変えない。

> 狙いは変えず、立つ場所だけを変える。そうすれば、毎回同じ投げ方で済む。

教わったときに言われたことで、いちばん覚えている言葉だ。

## ピンごとの移動量

| 残ったピン | 移動する枚数 | 方向 |
| --- | --- | --- |
| 2番 | 3 | 右 |
| 4番 | 6 | 右 |
| 7番 | 9 | 右 |
| 3番 | 3 | 左 |
| 6番 | 6 | 左 |
| 10番 | 12 | 左（ボールを替える） |

10番ピンだけは、曲がるボールだと外へ逃げきれないので、真っすぐ転がるプラスチックのボールに替える。

## スコアの記録

練習のたびにスペアの成功率を記録している。集計は小さなスクリプトで済ませている。

```ts
type Frame = { leave: string; converted: boolean };

function conversionRate(frames: Frame[]): number {
	if (frames.length === 0) return 0;
	const converted = frames.filter((frame) => frame.converted).length;
	return converted / frames.length;
}
```
