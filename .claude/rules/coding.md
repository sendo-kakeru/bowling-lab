## コーディング規約

- export は基本的に named export で統一
- export するのは別ファイルで呼び出すものと FW の機能として export する必要があるもののみ
- 関数の返り値はできるだけ型を明示する。コールバック関数は任意
- 関数の引数は分割代入し、引数内で型定義
- `as` による型の誤魔化しは最小にし、できるだけ適切に型付けする。`as const` の使用は問題ない
- 関数の引数が複数あるものは基本的にオブジェクトで渡す

### Biome を入れるまでの間だけ書いておくもの

旧リポジトリでは Biome で強制していた。Biome を入れたらこの節は消す。

- `forEach` は使わず `for...of` を使う
- `any` を使わない
- Non-Null Assertion（`!`）を使わない
- 使っていない import と変数を残さない
