## CSS 規約

原則であり、見た目のために破るほうが妥当なら破ってよい。

- 基本的にはスコープ付きスタイルを使用。複数の部品で共有するものだけグローバル（`src/styles/`）
- 子コンポーネントのスタイルは props で `class` を渡す。受け取る側は `const { class: className, ...rest } = Astro.props` で受け、`class:list` に `className` を入れて `{...rest}` を展開する（親のスコープ属性も `rest` で渡ってくる）
- font-size は `rem` を使用
- line-heightは単位無し（例: 1.6）
- `vh` / `vw` の使用は横スクロールの発生や意図しない崩れを招くため極力避け、`dvh`、`svh` などで再現できないか慎重に検討する。
- コンポーネントの外側の余白（`margin`、兄弟との距離のための`padding`）と、外側から見た幅（`width: 100%`、`max-width`など）は、コンポーネント内に持たせず呼び出し側から渡す。
- 要素間は `gap` をメインに余白を調整
- レイアウトは `flex` より `grid` をメインに使用
- `gap` は縦横の方方向のみであれば絞って指定する（例: `row-gap`）
- `margin` / `padding` で要素間の上下を調整する際には下ではなく上方向に余白を付ける
- ダークモード対応は不要
- モバイルファースト（`@media (width >= 768px)` で上書き）。ブレークポイントは 768 / 1024 / 1280px、最小の画面幅は 375px
- 余白はトークン化せず、4px の倍数を `rem` で直接書く
- `!important` は使わない
- Markdown から変換した本文（記事、メモ）はクラスのない HTML で、ページのスコープ付きスタイルが届かない。グローバルの `.prose` で整える。固定ページの本文も同じ見た目にするため `.prose` で包む
